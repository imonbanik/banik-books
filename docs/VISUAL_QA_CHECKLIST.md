# Visual QA Checklist

Use this checklist after layout, CSS, or route changes.

## Core Viewports

- Desktop: 1440px wide.
- Laptop: 1280px wide.
- Tablet: 768px wide.
- Mobile: 390px wide.

## Journal Entry

- Logo and heading align with the wide journal panel.
- Brand subtitle reads `Simple accounting for growing businesses`.
- Journal number stays at the far right of the meta row.
- No top/right or bottom/right Exit button is visible.
- Buttons appear under the journal table in this order: `Add line`,
  `Clear all lines`, `Create Ledger`.
- Journal Note and Attachment are side by side on desktop.
- Journal Note and Attachment become readable and non-overlapping on mobile.

## Shared Checks

- Header/logo areas do not overlap page controls.
- Text fits inside buttons and cards.
- Tables remain readable or scrollable on mobile.
- Active root URLs and active folder URLs both load.
- Firebase login/logout UI still appears where expected.
